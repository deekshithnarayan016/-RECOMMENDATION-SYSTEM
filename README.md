# DESCRIPTION OF TASK

The objective of this project is to develop a Movie Recommendation System using Collaborative Filtering and Cosine Similarity techniques. The system analyzes user rating patterns and recommends similar movies based on user preferences.

A movie ratings dataset was created and processed using Pandas. Cosine Similarity was applied to identify relationships between movies and generate personalized recommendations. The recommendation system accepts a movie name as input and suggests similar movies that users may also enjoy.

This project demonstrates the practical application of Machine Learning in building intelligent recommendation systems used by platforms such as Netflix, Amazon, and Spotify.
